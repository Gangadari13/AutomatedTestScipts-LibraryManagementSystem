# Library Management System

A PHP-based library management system for managing book inventories, borrowers, and transactions efficiently.

## Features
- Add, edit, and delete books.
- Manage borrower details.
- Track book lending and returns.
- Generate reports for overdue books.

## Requirements
- PHP 7.4 or higher
- MySQL database
- Apache server (or any compatible web server)
